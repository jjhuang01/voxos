# PRODUCT.md — 产品决定，以及每个决定的代价

这一页不写愿景，只写**已经做掉的决定**：现象是什么、按什么原则定的、
代价写在哪。原则来自三个地方：Apple 的人机指南（不要猜、不要打断、
权限要说清）、乔布斯（一次打断必须值一次打断）、张小龙（用完即走、
别让用户思考）。凡是引用原则的地方，都必须能指到一行代码或一条测试。

## 一句话

**它应该像家电，不像软件。** 说一句话，事情做完，窗口消失。
没有账号、没有设置向导、没有「首次启动引导」——第一次双击就该能用。

## 已做的决定

| 现象 | 决定 | 依据 | 代价（写在哪） |
| :--- | :--- | :--- | :--- |
| 装上后说「打开微信」只得到一句「（dry-run）会打开微信」 | `workspace.dry_run` **默认 false** | 出厂即能用。演示模式是给开发者的，不该是给用户的默认值 | 想演练的人要自己去打开它；`config/settings.toml` 注释里写了 |
| 说一句听不懂的话，回「还没学会这句」 | 未配大模型时改成：能力清单 **+** 「复杂句子要先接大模型：voxos llm --set-key」 | 张小龙：不要让用户猜。把**系统的配置问题**说成**用户的表达问题**是最糟的一种 | 句子变长（TTS 多念 2 秒）；`core._no_action_reply` |
| 每句话都弹确认卡 | 只有**不可逆**才弹：红线、`send_message`、定时、大改 | 乔布斯：一次打断必须值一次打断。确认卡问多了就变成仪式，人会闭眼点允许 | 删东西的措辞（「删掉 / 清空 / 格式化 / rm -rf」）一律升级为确认；`config/redlines.toml [confirm]` |
| 沙箱没起来时，命令照样跑成功了 | 照样执行，但返回文本第一句就是「（沙箱没能应用，这次是直接执行的）」 | 用户以为有沙箱、实际没有，比一开始就说清楚危险得多 | 结果文本多一行；`tools._shell` |
| 发消息失败只说「执行失败」 | 直接说「系统设置 → 隐私与安全性 → 辅助功能」 | iOS 的权限范式：告诉用户去哪个开关，而不是解释错误码 | 认 5 种错误串；`messaging._HINTS` |
| 定时任务到点时弹确认卡，没人看，超时按拒绝 | 创建任务时确认一次，到点直接执行 | 「一次授权，长期生效」。半夜弹卡等于这条任务永远不会执行 | `approved` 字段跟着任务落盘；`scheduler.add` |
| 窗口占 Dock、抢焦点、关掉进程还在 | `NSApplication.setActivationPolicy(.accessory)`，右上角，`canJoinAllSpaces`，关窗即退 | 它是个家电，不是个 App。用完即走，不留看不见的常驻 | 没有菜单栏图标；`native/VoxOSWindow.swift` |
| 「打开浏览器」会命中 `wechatwebdevtools` | 应用名匹配按「完全相同 > 前缀 > 包含」排序，找不到就**列出真实存在的名字** | Apple HIG：不要猜。猜错的代价比说「没找到」大 | 多写 15 行匹配逻辑；`tools._find_app` |
| 一句话要等 1 秒才动 | 正则快通道 <2ms 先跑，命中就不叫模型 | 张小龙：即时反馈。能 2ms 答完的事不该等 4 秒 | 快通道只认十来种说法，复杂句子仍要慢通道 |
| 打开窗口要 2.9 秒 | 换掉 Chrome，用 79 行 Swift + WKWebView | 用户感知的「快」只有一件事：**窗口出现**。为此值得写一门新语言 | 多一个编译步骤、多一份 plist；见 `docs/PERFORMANCE.md §1.1` |

## 还在做 / 没做的（诚实清单）

1. **`esc` 收起胶囊**、**`⌘⇧Space` 唤起**：现在只能点 Dock 或双击 App。
   这是「用完即走」缺的最后一块，需要给窗口加全局热键（Carbon `RegisterEventHotKey`）。
2. **TTS 的语气**：现在念结果是一句话平铺直叙。长结果应该先念结论。
3. **胶囊的状态文案**：`待机` / `在听` 这类词还是系统视角，不是人的视角
   （人想知道的是「它在等我说话吗」）。
4. **失败之后的重试**：一次没听懂，用户得重新说一遍全句。
   应该记住上一句、允许「再说一遍」只补差异。

## 一条自我约束

上面每一条都必须是**能被测试或命令验证的行为**，不是形容词。
写不进 `docs/ACCEPTANCE.md` 的「产品优化」，都算没做。
